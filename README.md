# Werner Mendizabal

I am an independent game developer, software engineer, musician, and artist building developer tools, educational resources, and original games through **TecunHuman**.

My work focuses on making advanced creative and engineering workflows more accessible to indie developers. I release many of my tools, examples, and selected game projects as open source, use them in real games and prototypes, and share what I learn through tutorials and technical demonstrations.

My current focus is interactive audio and music technology for the [Godot Engine](https://godotengine.org/).

## Godot Audio Tools

### [godot-csound](https://github.com/nonameentername/godot-csound)

A Godot GDExtension that integrates [Csound](https://csound.com/) with Godot for real-time synthesis, procedural audio, dynamic music, effects, and other interactive audio systems.

Supports desktop, mobile, and web platforms.

### [godot-lv2-host](https://github.com/nonameentername/godot-lv2-host)

A Godot GDExtension for hosting LV2 audio plugins inside Godot projects.

It allows existing open-source instruments and effects to become part of games, interactive applications, and Godot-based music tools.

### [godot-vst3-host](https://github.com/nonameentername/godot-vst3-host)

A Godot GDExtension for hosting VST3 audio plugins inside Godot.

### [godot-distrho](https://github.com/nonameentername/godot-distrho)

A framework for building audio plugins with Godot using the DISTRHO Plugin Framework.

It allows developers to create audio plugins and their interfaces using familiar Godot workflows without first needing to build an entire C++ plugin development environment.

### [godot-synths](https://github.com/nonameentername/godot-synths)

A collection of open-source Csound synthesizers and interfaces built with Godot.

These instruments can be used as examples, standalone musical tools, or building blocks for interactive games.

### [godot-interactive-audio](https://github.com/nonameentername/godot-interactive-audio)

A playable demonstration of dynamic music and interactive audio in Godot.

Music and effects respond to player movement, location, environmental changes, and gameplay events using Csound, LV2, and VST3 integration.

## IndieGameDev.org

[IndieGameDev.org](https://github.com/nonameentername/indiegamedev.org) is an open-source, community-oriented resource for indie game developers.

The project is intended to provide news, articles, tutorials, project showcases, and practical resources while giving developers a place to contribute and share what they are building.

## TecunHuman

**TecunHuman** brings together my work on:

* Open-source tools for indie developers
* Tutorials and educational content
* Original games and interactive experiments
