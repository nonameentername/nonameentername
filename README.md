## Godot Audio Tools

### [godot-csound](https://github.com/nonameentername/godot-csound)
A Godot GDExtension that integrates [Csound](https://csound.com/) with Godot for real-time synthesis, procedural audio, dynamic music, effects, and other interactive audio systems. Supports desktop, mobile, and web platforms.

### [godot-lv2-host](https://github.com/nonameentername/godot-lv2-host)
A Godot GDExtension for hosting LV2 audio plugins inside Godot projects — bringing existing open-source instruments and effects into games, interactive applications, and Godot-based music tools.

### [godot-vst3-host](https://github.com/nonameentername/godot-vst3-host)
A Godot GDExtension for hosting VST3 audio plugins inside Godot.

### [godot-distrho](https://github.com/nonameentername/godot-distrho)
A framework for building audio plugins with Godot using the DISTRHO Plugin Framework — create audio plugins and their interfaces using familiar Godot workflows, no C++ plugin dev environment required.

### [godot-synths](https://github.com/nonameentername/godot-synths)
A collection of open-source Csound synthesizers and interfaces built with Godot — usable as examples, standalone musical tools, or building blocks for interactive games.

### [godot-interactive-audio](https://github.com/nonameentername/godot-interactive-audio)
A playable demonstration of dynamic music and interactive audio in Godot. Music and effects respond to player movement, location, environmental changes, and gameplay events using Csound, LV2, and VST3 integration.
